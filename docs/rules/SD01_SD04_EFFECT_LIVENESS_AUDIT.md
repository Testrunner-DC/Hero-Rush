# SD01–SD04 单卡实战效果与决策活性审计

- 规则基线：官方规则 1.02、`public/cards.json` 卡面文本、两份 starter effect spec。
- 审计范围：当前 V2 准入的 72 张角色卡（SD01–SD04 各 18 张）；冲击卡无角色效果，不计入本表。
- 通过标准：来源区域和时机正确；费用/前段成功后才处理“如此做后”；合法目标可在当前 UI 选择；目标失效或为空不会留下无法回答的决策；每回合次数与持续值实时重算。
- 交互约定：手牌、基地、战区、结附卡直接在场面选择；撤退区与虚空区打开区域选择器；纯位置直接点击高亮区域；角色与位置复合选择先点角色再点区域。

## 通用防卡死结论

1. 触发效果在实际轮到结算时重新计算合法目标；同时效果造成旧目标离场时，失效效果安全跳过。
2. 起动效果在建立决策前验证 `min/max/choices`；目标不足时不允许进入无法回答的决策。
3. 目标区域与 UI 一致：撤退/虚空使用区域选择器，场面卡直接高亮，纯位置直接点击，复合位置会在选卡后点亮。
4. 所有原子执行后继续执行状态不变量检查；“如此做后”统一使用 `requiresPreviousSuccess` 门控。
